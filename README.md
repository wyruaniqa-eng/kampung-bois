# Kampung Bois

Browser-hosted build of Kampung Bois. Open the GitHub Pages URL to test the 3D survival game.

The page loads the game client. For multiplayer, a separate WebSocket server must be deployed and its secure `wss://` URL entered in the Multiplayer panel. See the downloadable v3 project ZIP for the Node server source and setup instructions.

Controls: WASD / arrow keys and mouse on desktop; touch controls on mobile. Requires internet access for the Three.js CDN.
